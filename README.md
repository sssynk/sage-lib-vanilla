### Local Development

#### Getting Started

Install SASS:
```bash
$ npm install -g sass
```

Build the stylesheet:
```bash
$ sass assets/stylesheets/index.scss dist/sage.css
```

Use the stylesheet as an import:
```html
<link rel="stylesheet" href="dist/sage.css">
```
